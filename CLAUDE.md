# CLAUDE.md — нотатки для роботи над проєктом

Браузерна покрокова стратегія «Битва за Україну: Лінія дронів». Українська мова в інтерфейсі й коментарях.
Огляд — `README.md`, логіка й формули — `docs/DESIGN.md`.

## Команди

```bash
npm run dev          # http://127.0.0.1:5273  (порт 5273, а не 5173 — 5173 зайнятий іншим проєктом автора)
npm test             # vitest: tests/*.test.ts (рушій, карта, системи, UI-смоук, фаззинг)
npm run typecheck    # tsc --noEmit (strict, noUnusedLocals)
npm run sim -- 8 --normal   # симуляція ШІ проти ШІ; --boost, --verbose
npx tsx scripts/dump-map.ts # SVG карти у .debug/ для налагодження геометрії
```

## Архітектура

* `src/engine/` — чистий детермінований рушій, **без DOM**. Стан — `GameState` (JSON; випадковість — `state.rng`).
  Усі зміни стану йдуть через `applyOrder` (`orders.ts`) — і для людини, і для ШІ.
* `src/engine/config.ts` — *увесь* баланс (складність — окремі таблиці для гравця за УА та за РФ). Сценарії: `scenario.ts`
  (базовий «Жовтень 2026») + `scenarios.ts` (метадані та перевизначення, напр. «Лютий 2022»). `techs.ts` — технології й контрзаходи. Кеш модифікаторів
  `getMods` треба скидати `invalidateMods(state)` після зміни технологій/ефектів.
* `src/engine/map/` — карта генерується в коді (контури країн вручну → діаграма Вороного → полігони).
  Суміжність береться з геометрії; ручні виключення — `EXTRA_EDGES`/`BLOCKED_EDGES` у `map/regions.ts`.
* `src/ui/store.ts` — стан застосунку (вибір, скасування, автозбереження, цикл ходів ШІ з паузами).
  `map.ts` — SVG; `panels.ts`/`modals.ts` повертають HTML-рядки, події — делегуванням за `data-act` у `main.ts`.

## Правила роботи

* Змінюєте баланс → `npm test` + `npm run sim -- 8 --normal` (дивимось тривалість, захоплення, UA-земля).
* Змінюєте правила → оновіть текст у `rulesModal()` (`ui/modals.ts`) і `docs/DESIGN.md`.
* Нові поля `GameState` мають лишатися JSON-серіалізованими (жодних Map/Set/функцій).
* Не використовуйте `Math.random`/`Date` у шляхах, що змінюють стан, — тільки `rng.ts`.
* Автозбереження: `localStorage['b4ua.save.v1']`; при зміні формату стану піднімайте `GAME_VERSION`.

## Нотатки

* У Browser-панелі Claude скриншоти можуть відставати на крок — додайте `wait` перед знімком; `rAF`
  там призупиняється, тому оновлення UI йде через `setTimeout`.
* Vite HMR перезавантажує сторінку при правках — не редагуйте файли під час виконання JS-сценарію в ній.
